# Портфолио — спек (2026-11-03)

Одностраничник с видеоработами. Хостинг: GitHub Pages (`имя.github.io`), без своего домена.

## Страница
- Тёмный фон. Шапка: имя, строка о себе, контакты.
- Теги-фильтры: Все · Художественные · Реклама · AI · Говорящая голова · Анимация. Одна работа может иметь несколько тегов.
- Сетка «разброс с воздухом»: карточки разной ширины, вертикальные и горизонтальные, со смещениями и пустотами. Раскладку считает JS (skyline-упаковка по невидимым колонкам + случайные отступы, seed фиксирован). При смене тега карточки плавно переезжают.
- Карточка: обложка; при наведении — беззвучный луп 4 с + название и клиент. На телефоне луп играет, когда карточка в кадре.
- Клик — полноэкранное окно с полным видео: свой mp4, YouTube, Vimeo, Instagram, TikTok (iframe), иначе кнопка-ссылка. Esc / клик по фону закрывает.

## Данные
- `works.json` — список работ: `id, src | url, title, client, tags`.
- `tools/build_media.py` — из исходников делает `media/<id>.mp4` (полное, H.264, ≤1080p), `media/<id>.jpg` (обложка), `media/<id>_loop.mp4` (4 с, без звука), и пишет `works.js` для сайта (с размерами кадра).
- Работа только по ссылке (`url`, без `src`) — обложка берётся из `poster`, если задан.

## Ограничения
- GitHub: файл ≤100 МБ, репо ~1 ГБ, трафик ~100 ГБ/мес. Полные видео жмём до ~10–25 МБ.
